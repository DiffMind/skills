# DiffMind AI

让你的 AI 智能体连接 DiffMind，查最新资料、检索中英文论文、下载文献全文，也能让多个模型分别回答同一个问题。

[DiffMind 官网](https://www.diffmind.ai)

## 功能概览

- **联网检索**：查找网上的新进展，结合搜索结果整理信息与来源。
- **文献检索**：支持中英文文献的标准检索和 AI 文献检索，按语言、年份等条件筛选结果。
- **文献下载**：对检索到的论文申请全文下载；是否可下载、免费额度及点数以实际结果为准。
- **多模型回答**：查看账号当前可用模型，让多个模型独立回答，按模型分别展示完整内容。
- **使用记录**：前往 DiffMind 网站查看调用历史。

## 安装


```bash
npx skills add https://github.com/DiffMind/skills --skill diffmind-ai
```

安装后，告诉智能体：

> 连接我的 DiffMind 账号。

安装 Skill 文件后，还需要完成账号连接。智能体会根据当前客户端引导授权；连接是否可自动配置，取决于客户端提供的能力。

## 连接账号

需要一个可用的 DiffMind 账号。可前往 [DiffMind 官网](https://www.diffmind.ai) 登录。

| 客户端 | 授权方式 |
| --- | --- |
| Codex、Cursor、Claude | OAuth，在浏览器登录并确认授权 |
| WorkBuddy、豆包 | 配对码，提供 DiffMind 登录邮箱和一次性配对码完成兑换 |

OAuth 首次连接默认申请检索和模型聊天两项权限，由用户在授权页面确认。已有连接如果只获得检索权限，使用模型聊天前需要补充授权。

使用 WorkBuddy 或豆包时，打开 [DiffMind 官网](https://www.diffmind.ai)，进入「个人资料 → 凭证」生成配对码，按智能体提示提供登录邮箱和配对码。请勿发送密码、Cookie 或长期访问令牌。

## 使用示例

### 联网检索

网上的新进展，交给 DiffMind 帮你找。

> 用 DiffMind 查一下：近两年 GLP-1 这类药，临床上有什么新进展？

### 文献检索

用一句话描述研究主题，检索相关论文。

> 用 DiffMind 帮我找近十年的英文论文，看看 GLP-1 受体激动剂对 2 型糖尿病患者的心血管结局有什么影响。

> 用 DiffMind 检索关于高血压的中文文献，语言设为 ZH。

已有检索结果后，可以继续筛选：

> 在刚才这次检索结果中，只保留近五年的中文文献，并告诉我符合条件的数量。

### 文献下载

找到希望保留的论文后，继续提出下载请求。

> 用 DiffMind 把刚才列表里的前两篇论文全文下载下来。

下载前会查询费用预估，是否需要进一步确认以预估结果为准。全文不可得时会说明情况，不把摘要当作全文。

### 多模型回答

先查看当前账号可用的模型，再选择参与回答的模型。

> 帮我看看，我的 DiffMind 账号目前能用哪些模型。

> 用 DiffMind 选三个可用模型，让它们分别介绍自己。

> 用 DiffMind 让几个模型分别评价这项研究的方法、优点和局限，完整展示各自回答。

模型按账号实际可用列表选择，不固定承诺某个模型或版本始终可用。

### 使用记录

想回头看看用过什么，前往 [DiffMind 网站](https://www.diffmind.ai) 查看。

## 点数与确认

- 账号授权与付费调用分别确认；完成授权不代表同意付费调用。
- 每次新的付费搜索或模型生成批次开始前，智能体会提示可能扣除点数，并等待确认。
- 模型列表等只读查询不启动模型生成，无需生成费用确认。
- 文献下载按预估结果、账号免费额度及服务端规则执行。
- 模型回答按 Token 用量结算，具体费率和可用能力以服务端返回为准。

## 何时使用

明确说“用 DiffMind”，或在支持的客户端中调用 `$diffmind-ai`。普通问答、翻译或未指定 DiffMind 的请求，不会仅因为安装了本 Skill 就自动发起 DiffMind 调用。

## 客户端与运行条件

本 Skill 提供 Codex、Cursor、Claude、WorkBuddy 和豆包的接入说明。实际可用性取决于客户端的 Skill、MCP、OAuth 或配对凭据支持，以及网络访问条件。
