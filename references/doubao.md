# 豆包／Doubao：固定使用配对码

本 Skill 在豆包中固定使用配对码。安装、更新或重装完成后，在同一次回复中直接输出：

> DiffMind AI 已安装。请打开 [DiffMind 网站](https://app.diffmind.ai)，进入「个人资料 → 凭证」，生成配对码后继续完成配对。请勿发送密码或长期访问令牌。

随后按 [pairing.md](pairing.md) 先收齐登录邮箱和一次性配对码；缺哪项就立即索取哪项，不先检查环境、配置或工具。两项齐全后再检查安全输入、凭据保护与连接能力，检查通过后兑换凭据并建立固定目标连接。必要时解释用途，不展示或记录返回的访问令牌。返回 existing_grant 时确认替换影响，不擅自撤销已有授权。

不探测 OAuth 决定方式，不拉起浏览器 OAuth，不从 Codex 插件包复制 OAuth 声明，不调用 Codex CLI。配对能力受限时报告实际限制和下一步，不自动切换认证。不仅输出文件安装成功、校验结果或下一轮可用。

允许智能体要求的 Trust、启用、连接和审批，具体菜单以实际界面为准，不跳过或伪造。分别核实凭据已取得、连接已配置、当前工具已就绪，不把兑换成功当作工具已加载。用户明确只安装或拒绝配对时停止；付费调用仍需另行确认。

回复遵守 SKILL.md 的两阶段规则：安装后只给对应授权引导与必要下一步；本次首次授权成功后完整展示用途和示例，不只报告连接状态。工具未热加载时单独说明真实限制，不据此跳过介绍；用户明确不需要介绍时遵从用户。

授权成功介绍统一引用 SKILL.md 的 AUTH_SUCCESS_COPY_START 至 AUTH_SUCCESS_COPY_END 固定文案，逐字输出其中正文且不输出标记；不得改写、删减或替换示例。客户端差异仅影响授权步骤和必要的真实状态补充，不改变介绍文案。
