# Claude：固定使用原生 OAuth

本 Skill 在 Claude 中固定使用 Claude 自己的 MCP OAuth，不使用配对码，不借用 Codex CLI 或其他客户端凭据。

安装后立即输出：“DiffMind AI 已安装。接下来连接你的账号，是否现在打开登录授权？授权本身不扣点，付费调用前会另行确认。”用户已明确同意本目标连接或回复“授权”时直接继续，不重复询问；只有安装请求时先等待用户确认。

使用当前 Claude 智能体真实提供的远程 MCP 配置和授权操作，固定 URL 为 `https://mcp.diffmind.ai/mcp/open`，传输 Streamable HTTP。桌面、CLI 和云端不能仅凭名称推断管理入口；CLI 参数以当前版本帮助为准，不猜菜单或命令。缺少自动能力时引导用户使用已核实的原生设置／登录入口，不退回配对码。

客户端负责标准服务发现、登记、PKCE、回调、Token 保存与刷新。用户本人在浏览器确认；不手工构造回调、不索取 Token、不跳过智能体 Trust 或权限确认。首次连接统一申请 web:search 与 model:chat 两项，提前说明分别对应检索与模型聊天，由用户确认；用户明确要求单项时遵从用户。客户端不能指定范围时核对实际授予结果，不假称已获得两项。

授权失败时按实际响应解释，invalid_redirect_uri 请管理员核对真实回调，不反复登录或更换认证绕过。完成后验证当前智能体目标工具已加载，再继续原任务；授权成功与工具就绪分别判断，付费调用仍需独立确认。用户明确只安装或拒绝连接时停止。

回复遵守 SKILL.md 的两阶段规则：安装后只给对应授权引导与必要下一步；本次首次授权成功后完整展示用途和示例，不只报告连接状态。工具未热加载时单独说明真实限制，不据此跳过介绍；用户明确不需要介绍时遵从用户。

授权成功介绍统一引用 SKILL.md 的 AUTH_SUCCESS_COPY_START 至 AUTH_SUCCESS_COPY_END 固定文案，逐字输出其中正文且不输出标记；不得改写、删减或替换示例。客户端差异仅影响授权步骤和必要的真实状态补充，不改变介绍文案。
